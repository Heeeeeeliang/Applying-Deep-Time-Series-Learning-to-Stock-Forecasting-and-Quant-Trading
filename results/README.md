# Results

Verbatim output artifacts that the README refers to. Every number cited in
the README of this repo can be traced to a file here.

## Tables

| File | What it contains |
|---|---|
| `ablation_table.csv` | All 11 ablation runs, full metrics. Generated by `tools/build_ablation_table.py` from each run's `metrics.json`. Run 11 marked `is_final = 1`. |
| `backtest_metrics.json` | Run 11's `metrics.json` verbatim. The headline numbers in the README's "Headline metrics (Run 11)" block read from this file. |
| `ch2_standardised_results.json` | The 9-method direct-prediction-ceiling table. Per-method aggregate **and** per-ticker breakdown. Generated by `notebooks/01_direct_prediction_ceiling/`. |
| `vol_prediction_v3_results.json` | Layer 1 model comparison (Naïve, Historical Mean, Multi-Scale LSTM, LightGBM block+daily, LightGBM + LSTM emb). DA in the 0.80–0.84 range. |
| `meta_label_v2_results.json` | Layer 3 trade-filter (meta-label) results. |
| `turning_point_summary.md` | Layer 2 (MultiScaleCNN) precision/recall trade-off across thresholds 0.5–0.95, per ticker, separately for top and bottom. |
| `all_tables.md` | Combined LaTeX-friendly table dump used in the thesis appendix. |

## Reproducing

```bash
# 1. Pull the data and checkpoints
bash quickstart.sh

# 2. Re-run the ceiling study
jupyter lab notebooks/01_direct_prediction_ceiling/01_nine_method_ceiling.ipynb

# 3. Re-run the volatility / turning-point layers
jupyter lab notebooks/02_volatility_layer/01_volatility_lightgbm.ipynb
jupyter lab notebooks/03_turning_point_layer/01_multiscale_cnn.ipynb

# 4. Re-run the end-to-end pipeline + ablation table
jupyter lab notebooks/04_backtest_and_ablation/01_end_to_end_pipeline.ipynb
python tools/build_ablation_table.py    # regenerates ablation_table.csv
```
